# Splurter native sources

See the [repository README](../README.md) for what Splurter is, how to install it and how to build it.

- `mac/` Swift menu-bar app (`build_app.sh`, `build_app.sh --install`)
- `android/` Kotlin / Compose app (Gradle)
- `icons/` icon generator (`swift icons/make_icons.swift`)
- `package.sh` release packaging

Wire format: [../docs/PROTOCOL.md](../docs/PROTOCOL.md).
